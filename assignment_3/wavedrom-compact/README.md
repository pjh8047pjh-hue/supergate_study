# WaveDrom: Cycle and clk complete set

전체 파형은 Cycle 바로 아래에 clk을 함께 표시합니다.

64/65/63클럭 각각 전체와 세부 파형입니다. 세 경우 모두 C390까지 시뮬레이션했습니다.
모든 행은 period: 0.5로 통일했습니다. 한 글자는 반 클럭, Cycle 숫자 하나는 한 클럭 폭입니다. | 위치는 같은 그림의 모든 행에서 일치합니다. 중간 클럭은 생략하므로 실제 시점은 Cycle 행으로 확인합니다.

C0는 첫 입력을 저장한 상승 에지입니다. ena와 din은 하강 에지에서 바뀝니다. C384=128×3은 추가 대기 확인 지점이며, 입력 파이프라인의 세 번째 출력 예정 시점과는 다릅니다.

| Input interval | Input attempts | Verified outputs |
|---|---|---|
|64|C0, C64, C128|H0 at C127, H1 at C191, H2 at C255|
|65|C0, C65, C130|H0 at C127, H1 at C192, H2 at C257|
|63|C0, C63, C126|H0 at C127, H1 at C190; no H2|

63클럭의 세 번째 입력은 C126에 저장되지 않습니다. 수락되었다면 예상되는 출력 시점은 C253이며, 이 시점과 C384 이후에도 H2가 없음을 표시했습니다. 64/65클럭은 H2 출력 후 C384에서 이미 IDLE 상태입니다.

세부 파형은 네 구간을 연결합니다: C125~C131(세 번째 입력과 H0), H1 전후 3클럭, H2 예상 시점 전후 3클럭, C383~C385. 세 경우 모두 같은 화면 폭입니다.
D0/D1/D2: 실제 입력. M0/M2: 저장된 메시지. H0/H1/H2: 기준값과 일치한 해시. IV: 초기 상태. Sn/Tn: 첫 입력/세 번째 입력의 G 연산 n회 후 저장된 상태. 실제 버스 값은 signal-values.json에 있습니다.
