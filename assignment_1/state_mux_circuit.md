## State bank: 16 x 64 bits

~~~text
     G output                  write / hold             initial / run             state register

 a_next[63:0] ----> [ MUX1 -> MUX2 -> FF ] x 4 ----------------------------------> state words  0..3
 b_next[63:0] ----> [ MUX1 -> MUX2 -> FF ] x 4 ----------------------------------> state words  4..7
 c_next[63:0] ----> [ MUX1 -> MUX2 -> FF ] x 4 ----------------------------------> state words  8..11
 d_next[63:0] ----> [ MUX1 -> MUX2 -> FF ] x 4 ----------------------------------> state words 12..15

                              MUX1.0 <----------------------------------------- FF.Q  (feedback)
                              MUX1.1 <--- corresponding G output
                              MUX1.S <--- cnt_en & (corresponding sel == word index)

                                      MUX2.0 <--- MUX1 output
                                      MUX2.1 <--- INIT_STATE[word]
                                      MUX2.S <--- ena

                                                   FF.CLK   <--- clk
                                                   FF.CLR_n <--- rstb
                                                   FF.Q     ----/64-----------> state[word]

 state[1023:0] ---------------------------------------------------------------/1024----> state_mux
~~~

## State write port: address and data

~~~text

                                        +-----------------------------------+
                                        |       STATE REGISTER BANK         |
                                        |            16 x 64 bits           |
                                        |                                   |
 sel_d[3:0] ------------/4-------------> | ADDR_D                            |
 d_next[63:0] -----------/64------------> | DATA_D                            |
 cnt_en ----------------/1-------------> | WE_D                              |
                                        |                                   |
 sel_a[3:0], a_next[63:0] -------------> | ADDR_A / DATA_A                   |
 sel_b[3:0], b_next[63:0] -------------> | ADDR_B / DATA_B                   |
 sel_c[3:0], c_next[63:0] -------------> | ADDR_C / DATA_C                   |
 cnt_en ------------------------------> | WE_A / WE_B / WE_C                |
                                        |                                   |
 INIT_STATE[1023:0] -----/1024----------> | INIT                              |
 ena -------------------/1-------------> | LOAD_INIT                         |
                                        |                                   |
 clk ---------------------------------> | > CLK                             |
 rstb --------------------------------> o CLR_n                             |
                                        |                                   |
                                        | Q[1023:0] +----/1024----> state_mux |
                                        +-----------------------------------+

~~~
